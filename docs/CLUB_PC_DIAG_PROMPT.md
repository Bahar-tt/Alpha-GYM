# پرومپت فقطخواندنی برای اوپنکد باشگاه

لطفاً روی کامپیوتر باشگاه فقط بخوان، هیچ فایلی را تغییر نده، سرویسی را ریاستارت نکن، اثر انگشتی ثبت نکن و UFS را reset نکن.

دستور:

```powershell
py -3 diag_club_pc_readonly.py --path "C:\alpha-gym-module-native" --tail-lines 100 --foh 800008 800009
```

سپس خروجی JSON را کامل (یا حداقل قسمتهای `source`, `ufs`, `logs`, `processes`, `queues`) برگردان و به این سوالها جواب بده:

1. آیا مسیر نصب وجود دارد و کدام نسخهٔ `Agent.cs`, `Hardware.cs`, `GymBridge.cs` آنجاست؟ (هشها را بگو، محتوای `agent.config.json` را نه)
2. آیا اصلاحات `FohReadLoop_End/Start + CancelEnroll` و قفلِ enroll در کد نصبشده هست؟ با شمار خط/نشانهها ثابت کن.
3. آیا لاگ آخرین تلاش `800008` نشان میدهد SDK callback آمد یا نه؟ آیا `native-stuck` دیده میشود؟ آیا همان enrollmentId دو بار شروع شده؟
4. آیا الگوی `800008` و `800009` در UFS پیدا میشود؟ فقط بهعنوان سرنخ، نه حکم نهایی؛ نتیجه را «heuristic» بنام.
5. آیا agent زنده است، هیچ enrollment pendingای در صف هست، و وضعیت سنسور بهگونهای هست که تست `800009` ایمن باشد؟

هیچ کلید، رمز، `agent_key` یا لاگ خام حاوی اسرار در چت نفرست.
